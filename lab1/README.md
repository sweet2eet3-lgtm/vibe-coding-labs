## Описание проекта

Feedback Assistant — Telegram-бот на Python для автоматизированного сбора обратной связи о качестве обслуживания клиентов.

Бот позволяет пользователям оценивать обслуживание по пятибалльной шкале и оставлять текстовые комментарии. Отзывы сохраняются в JSON-файле, а администратор получает уведомления и может просматривать статистику.

## Функциональные возможности

- `/start` — приветствие и список команд.
- `/feedback` — отправка оценки от 1 до 5 и комментария.
- `/stats` — количество отзывов и средняя оценка (только для администратора).
- `/help` — справка по командам.
- `/cancel` — отмена отправки отзыва.
- Проверка корректности оценки.
- Сохранение отзывов с датой и временем.
- Уведомление администратора о новых отзывах.

## Установка и запуск

1. Открыть папку проекта в Terminal.
2. Создать виртуальное окружение:

   `python3 -m venv .venv`

3. Активировать виртуальное окружение:

   `source .venv/bin/activate`

4. Установить зависимости:

   `pip install -r requirements.txt`

5. Создать файл `.env` по образцу `.env.example` и указать:

   `BOT_TOKEN=ваш_токен_бота`  
   `ADMIN_ID=ваш_Telegram_ID`

6. Запустить бота:

   `python3 bot.py`

## Структура проекта

- `bot.py` — основной код Telegram-бота.
- `requirements.txt` — зависимости проекта.
- `README.md` — документация.
- `.env.example` — пример настройки переменных окружения.
- `.gitignore` — исключения для Git.
- `prompt.txt` — запрос к ИИ для генерации бота.
- `feedback.json` — файл с отзывами, создаётся автоматически.
- `.env` — конфиденциальные настройки, не публикуются.

## Проверка работы

В ходе тестирования проверены:

- Запуск бота и команда `/start`.
- Отправка оценки и текстового отзыва.
- Сохранение данных в JSON.
- Получение уведомления администратором.
- Просмотр статистики через `/stats`.
- Работа команды `/help`.
- Обработка некорректной оценки.
- Отмена отправки отзыва через `/cancel`.

Доступ к статистике ограничен проверкой Telegram ID администратора.
