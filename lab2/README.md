# Лабораторная работа № 2 — Подключение бота к данным

**Университет:** ИТМО
**Автор:** Суруджян Арутюн Аршалуйсович
**Проект:** Feedback Assistant

## Описание

Telegram-бот для сбора и анализа отзывов пользователей с интеграцией файловых данных.

## Источник данных

Отзывы сохраняются в JSON-файле `feedback.json`. По запросу администратора бот фильтрует отзывы и экспортирует их в CSV.

Структура данных:
- user_id — идентификатор пользователя
- rating — оценка от 1 до 5
- comment — комментарий
- date — дата и время

## Команды

- /start — приветствие
- /feedback — оставить отзыв
- /stats — статистика администратора
- /reviews 5 — найти последние пять отзывов с оценкой 5
- /export — выгрузить отзывы в CSV
- /help — справка
- /cancel — отмена ввода

Команды /stats, /reviews и /export доступны только администратору.

## Технологии

Python 3, python-telegram-bot 20.8, python-dotenv, JSON, CSV.

## Запуск

1. Установить зависимости: `python3 -m pip install -r requirements.txt`
2. Создать `.env` с переменными BOT_TOKEN и ADMIN_ID.
3. Запустить: `python3 bot.py`

## Обработка ошибок

Бот проверяет корректность оценок, отсутствие отзывов, права доступа и ошибки чтения JSON.

## Результат

Реализованы поиск отзывов по оценке и экспорт данных в CSV. Существующие функции первой лабораторной сохранены.
