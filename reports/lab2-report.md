1. Цель работы

Научиться интегрировать Telegram-бота с файловыми источниками данных, реализовать поиск, фильтрацию и экспорт информации с использованием кода, разработанного при помощи LLM.

2. Описание интеграции

Для второй лабораторной работы я решил продолжить развитие Telegram-бота Feedback Assistant, созданного в первой лабораторной.

В качестве источника данных выбрал локальный JSON-файл feedback.json, в котором хранятся отзывы пользователей. Дополнительно реализовал преобразование данных в формат CSV.

Такой подход позволил использовать существующие данные, избежать подключения платных сервисов и продемонстрировать работу с двумя файловыми форматами.

Каждый отзыв содержит четыре поля:

user_id — идентификатор пользователя Telegram;

rating — оценка от 1 до 5;

comment — текст отзыва;

date — дата и время отправки.

3. Промпт для LLM

Для генерации нового функционала я использовал следующий запрос:

Улучши Telegram-бота Feedback Assistant, написанного на Python с использованием python-telegram-bot 20.8.

Сохрани существующие команды /start, /feedback, /stats, /help, /cancel и хранение отзывов в JSON.

Добавь команду /reviews <оценка> для поиска последних пяти отзывов по оценке и команду /export для выгрузки всех отзывов в CSV.

CSV должен содержать поля user_id, rating, comment, date.

Ограничь доступ к новым командам администратором, предусмотрев обработку неправильных оценок и отсутствия данных.

Используй стандартные библиотеки Python и сохрани существующий функционал.

Полная версия промпта сохранена в lab2/prompt.txt.

4. Реализация

Для реализации использовались Python 3, библиотека python-telegram-bot, python-dotenv, а также стандартные модули json, csv и io.

Были добавлены две команды:

/reviews 5 — бот загружает отзывы из JSON, фильтрует их по оценке и показывает последние пять подходящих комментариев.

Ключевой фрагмент:

matches = [
    item for item in load_feedback()
    if isinstance(item, dict) and item.get("rating") == rating
]

/export — бот преобразует сохранённые отзывы в CSV и отправляет файл администратору через Telegram.

Ключевой фрагмент:

writer = csv.DictWriter(
    output,
    fieldnames=["user_id", "rating", "comment", "date"],
    extrasaction="ignore",
)
writer.writeheader()

Обе команды доступны только пользователю, чей Telegram ID совпадает с ADMIN_ID.

6. Трудности и решения

Ошибка отступов в Python. После добавления обработчиков новых команд возникла ошибка IndentationError. Я проверил строки с номерами, обнаружил неправильные отступы и исправил их. После этого код успешно прошёл проверку py_compile.

Отсутствие зависимостей. При запуске возникла ошибка ModuleNotFoundError: No module named 'dotenv'. Проблему решил установкой библиотек из requirements.txt.

Отсутствие настроек. После установки зависимостей бот не находил BOT_TOKEN. Я подключил локальный файл .env с необходимыми настройками.

Отсутствие тестовых данных. При первом поиске бот не нашёл отзывов, поскольку в папке второй лабораторной ещё не было данных. После отправки нового отзыва поиск начал работать корректно.

Удалось сохранить функции первой лабораторной и добавить два инструмента для администратора: поиск отзывов и экспорт данных.
