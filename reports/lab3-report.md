## 1. Цель работы

Развернуть Telegram-бота для использования реальными пользователями, собрать обратную связь, проанализировать предложения и внести улучшения на основе полученных данных.

## 2. Выбор способа деплоя

Для тестирования был выбран **локальный запуск Telegram-бота с использованием Long Polling**.

Этот способ позволяет боту получать сообщения через Telegram Bot API без необходимости настройки отдельного веб-сервера или webhook.

**Причины выбора:**
- Возможность использовать уже разработанный проект.
- Отсутствие дополнительных расходов на хостинг.
- Простота запуска и тестирования.
- Доступность бота другим пользователям Telegram, пока программа работает на компьютере.

**Ограничение:** бот работает только при запущенной программе и доступном интернет-соединении на компьютере разработчика. Поэтому данный способ подходит для тестирования, но для постоянной эксплуатации рекомендуется облачный хостинг.

## 3. Подготовка к запуску

В качестве основы использовался бот, разработанный в лабораторных работах № 1 и № 2.

Была создана отдельная директория `lab3`, содержащая исходный код, зависимости и документацию.

Основные компоненты:
- `bot.py` — логика Telegram-бота.
- `requirements.txt` — зависимости Python.
- `README.md` — документация.
- `prompt.txt` — промпт для разработки с помощью LLM.
- `.env` — локальные переменные окружения, не предназначенные для публикации.

Для взаимодействия с Telegram используется библиотека `python-telegram-bot`.

Бот поддерживает следующие функции:
- `/start` — запуск бота.
- `/feedback` — отправка оценки и комментария.
- `/stats` — статистика для администратора.
- `/reviews` — поиск отзывов по оценке.
- `/export` — экспорт отзывов в CSV.
- `/help` — справка.
- `/cancel` — отмена заполнения отзыва.

## 4. Процесс запуска

Также была проверена команда `/feedback`: бот предложил пользователю поставить оценку от 1 до 5.

**Результат:** бот был доступен пользователям Telegram во время работы программы на компьютере.

## 10. Возникшие сложности и решения

**Сложность 1.** Первоначальный интерфейс требовал ручного ввода команд.

**Решение:** реализовано интерактивное меню с кнопками.

**Сложность 2.** Необходимо было внести изменения, не нарушив существующие функции.

**Решение:** использованы существующие обработчики Telegram-бота, после чего проведена проверка синтаксиса и ручное тестирование.

**Сложность 3.** Локальный запуск зависит от работающего компьютера.

**Решение:** для текущего этапа выбран краткосрочный пользовательский тест. В дальнейшем возможен перенос на облачную платформу.
